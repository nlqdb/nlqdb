# AI-permissive — mirrors `apps/web/public/robots.txt` (AEO/GEO). We want
# citations from Perplexity / ChatGPT / Gemini / Claude as a primary
# acquisition channel, and this host is the one a coding agent gets pointed
# at: the "Give your agent memory" guide plus /llms.txt, /llms-full.txt.
#
# Why the file exists at all: with no robots.txt of its own, this host served
# only Cloudflare's *managed* block, which Disallows ClaudeBot, GPTBot,
# Google-Extended, CCBot and friends — the exact crawlers behind the coding
# agents the guide is written for. Cloudflare keeps emitting that block above
# this content; declaring the same user-agent again merges the groups, and
# Google resolves equal-length conflicting rules in favour of the least
# restrictive one, so `Allow: /` re-opens the host.
#
# Disallows repeat in every group — a crawler that matches a named group
# ignores the `*` group entirely. /cdn-cgi/ is Cloudflare's injected
# scaffolding (its email-protection links 404 for crawlers). There is no
# `/v1/` here; that disallow belongs to the marketing host's API surface.

User-agent: GPTBot
Allow: /
Disallow: /cdn-cgi/

User-agent: ClaudeBot
Allow: /
Disallow: /cdn-cgi/

User-agent: anthropic-ai
Allow: /
Disallow: /cdn-cgi/
